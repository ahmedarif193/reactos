HAL / PCI Bring-Up Tasks for xHCI (Intel 7-Series, VID 8086 DID 1e31)

- [ ] Restore ECAM / MMCONFIG access
  - Fix firmware/quirk path that disables ECAM globally; allow PCI Express config space via MMCONFIG.
  - Keep CF8/CFC legacy path reliable as fallback.

- [ ] PCI command defaults
  - Bus driver should set MEM + BusMaster bits before StartDevice; avoid miniport-side workarounds.

- [ ] Validate PCI config reads
  - Ensure VID/DID and capability reads are stable via the chosen config path (ECAM or CF8/CFC) so quirks are based on real IDs.

CMake is used to build ReactOS.

Here you will find what you'll need to write nice CMakeLists.txt files for ReactOS.
CMake standard functions are available too. See http://www.cmake.org/, or type cmake --help-html in your shell to get the full documentation.

Optional arguments are marked with [brackets], input is marked with <comparison signs>.

---------------------------------------------------------------------------------------------------------------------------------------------
set_module_type(<target> <type> [UNICODE] [BASEADDRESS <baseaddress>] [ENTRYPOINT <entrypoint> <stacksize>])

This sets the type of the module, and takes care of setting common linker options or definitions to the specified target, module file extension, etc. Please always use this when adding a module to ReactOS build.

ARGUMENTS:
<target>: name of the target. The module must have been added with add_executable or add_library before calling this function.
<type>: one of win32gui, win32cui, win32dll, win32ocx, cpl, nativecui, nativedll, kernelmodedriver.
UNICODE: provide this if the module was written for unicode API.
<baseaddress>: provide this if you want your module to have a different base address than the default one (according to <type>). For win32dll modules, please use baseaddress.cmake instead.
<entrypoint>: name of the function which will be the entry point of the module. If it's not provided, it's guessed from the module type.
<stacksize>: Size of stack required for the parameters of <entrypoint>.

TYPICAL USE:
set_module_type(msvcrt win32dll ENTRYPOINT DllMain 12)

ros_add_rust_executable(<target> [CRATE_DIR <path>] [BINARY_NAME <name>] [TARGET_TRIPLE <triple>] [FEATURES f1;f2;...] [PROFILE debug|release] [ENV key=val;...] [DESTINATION <cd-path>] [NAME_ON_CD <name.exe>] [CD_FOR <list>] [NO_CAB] [SKIP_IF_MISSING])

Adds a Rust executable built with cargo, tailored for MinGW windows-gnu targets. It emits a custom target that builds the requested binary and can optionally package it into the ISO using add_cd_file.

ARGUMENTS:
<target>: CMake target name used to depend on the produced exe.
CRATE_DIR: Directory containing Cargo.toml (defaults to current source dir).
BINARY_NAME: The cargo binary name (defaults to <target>).
TARGET_TRIPLE: Override the Rust target triple (defaults from ARCH: i686-pc-windows-gnu or x86_64-pc-windows-gnu).
FEATURES: Semicolon-separated list of cargo features.
PROFILE: Force cargo profile directory (debug or release). Otherwise maps from CMake build type.
ENV: Extra environment entries passed to cargo (in addition to the cross-linker defaults).
DESTINATION/NAME_ON_CD/CD_FOR/NO_CAB: Optional packaging parameters forwarded to add_cd_file.
SKIP_IF_MISSING: Silently skip if Rust is not available.

PREREQUISITES:
- Host must have cargo/rustc and the appropriate windows-gnu target installed. See scripts/setup-rust-mingw.sh.

EXAMPLE:
ros_add_rust_executable(mytool CRATE_DIR ${CMAKE_CURRENT_SOURCE_DIR} BINARY_NAME mytool DESTINATION reactos/system32 SKIP_IF_MISSING)

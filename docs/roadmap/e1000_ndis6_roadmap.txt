E1000 NDIS 6.x Roadmap (Intel 82574L and compatible)
=====================================================

How to use
----------
- Mark each task with [x] when completed.
- Use [~] for partial/in-progress implementation.
- Keep this file as the single roadmap source for E1000 NDIS 6.x work.

Scope
-----
- Modernize legacy NDIS 5.x path to NDIS 6.x (`NET_BUFFER_LIST` model).
- Enable MSI-X interrupt model where available.
- Add RSS, checksum/segmentation offloads, and NDIS 6 power features.

Current -> Target
-----------------
- NDIS: 5.0 -> 6.30+
- Packet path: `NDIS_PACKET` -> `NET_BUFFER_LIST/NET_BUFFER`
- Send/receive: legacy miniport send/indicate -> `SendNetBufferLists` / `NdisMIndicateReceiveNetBufferLists`
- Interrupts: line-based registration -> `IoConnectInterruptEx` (MSI-X/message interrupts)
- Offloads: minimal -> checksum + LSO + RSS

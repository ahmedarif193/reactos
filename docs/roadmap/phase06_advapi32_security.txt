Phase 06 – Advapi32 Security, Credential, and Trace Infrastructure
=================================================================
Goal: replace the advapi32 Vista stub exports with working implementations. These
functions are essential for ETW tracing, credential management, SAFER policy, and
enterprise deployment tools.

Event Tracing for Windows (ETW)
------------------------------
- EnumerateTraceGuids (EtwEnumerateTraceGuids)
- WmiNotificationRegistrationA/W (EtwNotificationRegistration*)
- WmiReceiveNotificationsA/W (EtwReceiveNotifications*)
- SetTraceCallback / RemoveTraceCallback
- CloseTrace, WmiOpenTraceWithCursor, WmiCloseTraceWithCursor
- WmiQueryAllData*, WmiQuerySingleInstance*, WmiSetSingleInstance*, WmiSetSingleItem*,
  WmiOpenBlock, WmiCloseBlock, WmiExecuteMethod*, WmiParseTraceEvent, WmiGetNextEvent,
  WmiGetTraceHeader, WmiGetFirstTraceOffset

Rationale: modern diagnostics, PerfMon, and many system components depend on ETW. Without
functioning advapi32 ETW wrappers, higher-level APIs in kernel32 and user-mode drivers
will fail.

Credential Manager Enhancements
-------------------------------
- CredRenameA/W
- CredWriteDomainCredentialsA/W / CredGetTargetInfoA/W / CredProfileLoaded
- CredpConvertCredential / CredpConvertTargetInfo / CredpEncodeCredential /
  CredpDecodeCredential
- DuplicateEncryptionInfoFile / EncryptedFileKeyInfo / FreeEncryptedFileKeyInfo /
  SetUserFileEncryptionKey

Rationale: enterprise and browser credential stores call these routines for domain-aware
credential handling. Implementing them improves compatibility with Remote Desktop,
Outlook, and modern browsers.

SAFER Policy & Security Descriptor Helpers
------------------------------------------
- SaferGetLevelInformation / SaferSetLevelInformation / SaferSetPolicyInformation
- Saferi* internal helpers (ChangeRegistryScope, CompareTokenLevels, etc.)
- ConvertAccessToSecurityDescriptorA/W / ConvertSecurityDescriptorToAccessA/W
- SetEntriesInAccessListA/W / SetEntriesInAuditListA/W / TrusteeAccessToObjectA/W
- LookupSecurityDescriptorPartsA/W
- SetNamedSecurityInfoExA/W / GetNamedSecurityInfoExA/W / SetSecurityInfoExA/W

Rationale: these APIs are required by MMC snap-ins, AppLocker-like tools, and installers.
Safer policy support also unlocks `runas` restrictions.

Service Control Extensions & Miscellaneous
------------------------------------------
- I_ScSendTSMessage (Terminal Services messaging for services)
- ProcessIdleTasks / RegisterIdleTask / UnregisterIdleTask
- WdmWmiServiceMain (bridge for kernel-mode WMI providers)
- MSChapSrvChangePassword / MSChapSrvChangePassword2 (RAS authentication)
- InstallApplication / UninstallApplication / GetManagedApplications*

Implementation Strategy
-----------------------
1. ETW: leverage existing `advapi32_vista` infrastructure. Port Wine’s ETW controller or
   hook into ReactOS’s km/wm trace stack. Ensure session registration, notifications, and
   data queries behave like Windows.
2. Credential APIs: implement using the ReactOS credential manager service. Store domain
   credentials securely (LSA secrets, DPAPI). Provide encoding helpers consistent with
   Windows XP/Vista formats.
3. SAFER: integrate with the security policy engine. Many functions are table-driven and
   can reuse Wine’s logic. Ensure registry updates are transactional.
4. Security Descriptor Helpers: wrap `RtlSetSecurityObject`/`RtlQuerySecurityObject` and
   provide ACL editing convenience wrappers.
5. Testing: expand `winetests/advapi32/registry.c`, `security.c`, and add new tests for
   credential manager operations and ETW controller workflows.

Exit Criteria
-------------
- All targeted advapi32 stubs removed from the export inventory.
- ETW sessions can be started/stopped via `logman.exe` equivalent; credential manager
  operations succeed in tests; SAFER policy editing works in MMC snap-ins.
